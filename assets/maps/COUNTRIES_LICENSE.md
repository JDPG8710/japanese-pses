# Country boundaries

`countries-50m.json` is derived from Natural Earth 1:50m Admin 0 countries.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- License: public domain, https://www.naturalearthdata.com/about/terms-of-use/
- Retrieved: 2026-09-05
- Transformation: retain country names, label positions and polygon rings; round coordinates to 0.001 degrees. No external requests are needed when displaying the map.

This simplified map is a navigation aid, not a detailed boundary or sovereignty reference. Areas without a valid country code are drawn but not offered as independent country choices.
