# 小小设计师：产品设计工坊

追踪链：用户要求提高产品外观与零件质量 → 小学高年级（以六年级视觉与操作能力为目标） → 非课程绑定的设计与创作 → 小镇/世界 bubble 内部路由 → 原有挑战与排行榜契约。保留原内部 ID 与奖励范围。

手机同时显示正面与背面，可分别组装中框、屏幕、相机底座、独立镜头、闪光灯、传感器、按键、扬声器、充电口及装饰。产品为原创绘制的参考风格模型；参考 [Apple iPhone 16 Pro 外观](https://www.apple.com/newsroom/2024/09/apple-debuts-iphone-16-pro-and-iphone-16-pro-max/) 与 [华为 Mate 70 系列外观](https://consumer.huawei.com/cn/support/content/zh-cn16025269/)。

零件采用原生 Canvas 矢量路径、渐变与独立层，显示玻璃反光、金属边框、镜头玻璃、轮毂辐条、轮胎纹理和涡扇叶片。展示与点击坐标使用同一比例变换，不再拉伸产品。

## 创作与保存

拖拽或点击自动装入，靠近目标吸附；自由旋转、缩放、前后图层；10 色快捷调色及自定义颜色；画笔粗细、橡皮、撤销/重做；各套件的当前草稿可在同一会话内切换保留。移动端零件库水平滚动，“专注画布”扩大设计区。

“屏幕截图”输出整个当前工作台的 PNG（包含零件库、工具、选择框和配色），提供预览与下载。“导出作品”输出 1800×1200 的干净设计画布，移除网格、未组装参考与选择框。截图使用本应用 DOM 布局与本地画布绘制，无需请求整台电脑的屏幕权限。

全核心零件完成且有个性化操作才结算，示范预览不奖励；成绩保持 400–600，沿用现有排行榜分数范围。没有修改数据库或排行榜版本。

## 验证

测试覆盖套件零件唯一性、三种语言标签、目标引用、变换、暂停、撤销/重做、会话草稿、一次结算；1440/390px 真实浏览器的七套组装、PNG 截图与导出、触屏滚动/拖拽、专注画布及奖励流程；相邻鼓队、小镇 19→20→无限挑战、主回归与发布检查。本地完整发布门禁与相邻游戏回归通过；上线后核验八个街机资源、11 个排行榜接口及访客写入拒绝，全站健康检查 17/17 通过。
