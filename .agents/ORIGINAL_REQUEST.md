# 当初の開発要件

このファイルは、プロジェクト直下の `ORIGINAL_REQUEST.md` と同じ開発基準をエージェントから参照するための要約です。

## 目的

日本の小学生向け全教科学習ゲームを、学習指導要領、認知発達、安全な操作性、肯定的なフィードバックに基づいて継続的に改善する。

## 必須要件

1. 製品管理、ゲーム設計、知識グラフ管理、品質保証、修復の各エージェントを Director が順番に連携させる。
2. 画面上の教科、ゲーム、問題は必ず学年の学習範囲と一致させる。
3. 国語、算数、理科、社会、生活、外国語／英語に、それぞれ異なる学習目的と遊び方を用意する。
4. Web Audio API、Canvas／CSS 演出、段階的な誤答支援を使用し、罰を与えない。
5. 学年別漢字配当表1,026字と各教科の教材データを検証し、知識グラフを循環や行き止まりのない状態に保つ。
6. PC とモバイルの双方で十分な操作領域を確保し、選択中の項目を明確に強調する。
7. 全テストと実ブラウザー確認を完了し、証拠がそろうまでリリースしない。

詳細な受け入れ基準はプロジェクト直下の `ORIGINAL_REQUEST.md` を参照してください。
