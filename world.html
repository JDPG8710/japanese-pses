PIKO LOGIC LAB

Nine ways to practise thinking

Choose a puzzle, read its opening tutorial and try a short round. Start with the first difficulty. Guest practice needs no account; the five-minute timer begins after the tutorial. For an untimed start, use the worked examples below.

  • Circuit Relay

    Rotate pipe pieces until they form a connected route. Check that each connection has a matching opening in its neighbour; a piece facing the goal can still be disconnected.

  • Number Vault

    Complete a small Sudoku. Use the numbers missing from a row, then eliminate those already in the column or outlined region. Check all three constraints.

  • Codebreaker

    Compare the feedback from several guesses to infer a hidden code. Distinguish a correct symbol in the right position from one that belongs elsewhere.

  • Piko Pathfinder

    Plan the shortest safe route around rocks. Trace every intermediate square and count the moves before sending the robot; arriving by a longer route is not enough.

  • Triple Set

    Choose three cards whose features are each all the same or all different. Check each feature separately instead of choosing cards that merely look similar.

  • Shape Number Puzzle

    Use equations to find the number represented by a shape. Replace a known shape value in the next equation, then check the result against every clue.

  • Logic Lineup

    Arrange travellers from relative-position clues. “Before” need not mean “immediately before”; keep adjacency and ordering requirements separate.

  • Water Lab

    Plan fills, empties and pours to reach an exact volume within the move limit. Track both containers after every move and remember their remaining space.

  • Island Grid

    Connect every island with minimum total cost. A cheap connection is useful only if it helps connect the network; adding a cycle wastes an edge.
