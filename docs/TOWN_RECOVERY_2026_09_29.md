# 3D 小镇回退根因与手机操作修复

## 根因证据

- 原 3D 创作仍在 `origin/codex/learning-town-3d`，最新提交 `c24011c`，包括 `0aefd94` 的三维引擎、`d43cc22` 的手动跳跃、`9d85a70` 的街区扩展及后续赛车等改进。
- 修复前正式源码 `dff0cb6` 未包含这个分支。`git log HEAD..origin/codex/learning-town-3d` 显示 13 个未合并提交。
- `dff0cb6:src/town/TownApp.mjs` 引入 `TownScene.mjs`，其中构造函数执行 `canvas.getContext('2d')`；3D 分支引入 `TownScene3D.mjs`，创建 `THREE.WebGLRenderer` 和透视相机。
- 既有 `docs/TOWN_3D.md` 记录：3D 曾直接上传至 Pages 正式分支，但源码留在功能分支。随后基于 main 的整站上传重新带入旧版 2D。Pages 的生产分支标签不会自动将 Git 功能分支合并进 main。
- 上一次本站检查覆盖的是旧版故事和购物流程，没有断言 WebGL、三维关卡或相机。2D 功能检查通过不能证明 3D 功能仍存在；上一轮发布延续了这个回退。

## 修复与需求追踪

恢复既有创作 → 保留各自数学／英语难度 → 购物、计算、英语与记忆练习 → 原五个学习模式和四个休闲街机 → `/town?locale=zh` → 原关卡规则、真实 WebGL、实际键盘／双指输入、保存和浏览器验收。

- 合并完整 3D 分支历史；冲突处保留最新教材、SEO、AMC 8、学年筛选及既有引导链接。没有用新演示替代原来的场景。
- 原有存储键 `piko-town-v1`、故事进度、金币、角色和独立关卡保存契约保留。旧数据仍经过原 3D 迁移校验。
- 所有行走、跳跃、镜头、互动、帮助、声音及全屏控制位于画面内。方向键使用十字布局；右侧为跳跃／互动；半透明背景，触控目标至少 56px。空白覆盖区域不拦截镜头拖动。
- 返回、下一关、重试、记忆重播和提示按钮也移入画面；沿用原按钮和操作逻辑，不创建另一套奖励或状态处理。
- 修复小屏关卡强制双列；补充横屏布局。取消进入关卡时自动全屏，用户可以自行切换；全屏包含对话框，帮助不会留在不可访问的全屏区域之外。退出非全屏时不会产生未处理 Promise 异常。

## 防止复发

- `predeploy:pages` 获取最新 main，并拒绝缺少 main 已集成提交的工作目录。
- 发布前对最终 dist 运行真实 Chrome WebGL 验收：320／390／820／1440px、十座建筑、移动、相机保存、按钮边界及相互不重叠。2D 不再能通过发布门禁。
- 正式资源核对加入三维引擎、Three.js、建筑、学习模式及街机引擎；在线监控检查入口仍引用 3D 并存在 WebGLRenderer。
- 将本次整合后的源码推送 main，避免只更新正式资源却留下未合并源码。历史工作目录中旧的发布命令不能被新脚本追溯约束，后续发布应先更新 main 并运行标准 `npm run deploy:pages`。
