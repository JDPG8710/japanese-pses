`git fetch origin` 後の `origin/main`（`a6873e6`）を専用の管理対象worktreeへ取得した。元の `D:\Japanese PSES` は5コミット遅れており、複数の未コミット変更があったため、上書き・stash・混在はしていない。

最新版には既に7テーマの三言語ガイド、運営案内、404ページ、静的なゲーム紹介がある。過去の公開記録だけを根拠に現在の本番状態を正常とは判断しない。

## 今回見つけた本番の問題

匿名GET・リダイレクト非追従で、以下を確認した。

| URL | HTTP | HTMLタイトル／文字数 |
| --- | --- | --- |
| `/` | 200 | Piko Game の英語ホームタイトル／115624文字 |
| `/ja/guides/` | 200 | 同じホームタイトル／115624文字 |
| `/404.html` | 200 | 同じホームタイトル／115624文字 |
| `/missing-audit-20260929` | 200 | 同じホームタイトル／115624文字 |
| `/ja/guides/missing-audit-20260929` | 200 | 同じホームタイトル／115624文字 |

ガイドURLが独立した教材を返さず、存在しないURLもホームを200で返す。現在の配信成果物または配信設定とリポジトリの不一致が疑われる。どの配備で変わったかは未調査。今回のローカルPages互換プレビューでは、48件のサイトマップURLが正しいcanonicalを持つページを200で返し、不明URLが404を返すことを確認した。

AdSenseは具体的な不承認URLを示していないため、この問題だけが審査理由とは断定しない。

## 実装した改善

- バランスとネットワークのオリジナル解説を日本語・英語・中国語で追加。前提知識、完全な例題、段階的推論、誤答の理由、条件を変えた独立練習と答え、実際のゲームとの違いを掲載。
- 既存の教材生成器で6記事を静的HTML化。ログイン・JavaScriptなしで読める。資料庫、ゲームカード、サイトマップ、言語切替から到達できる。
- バランスは3条件をすべて満たす必要性と「合計を半分にする方法」の適用範囲を説明。ネットワークは最安の辺を並べるだけでは孤立点が残る例と最小コストの根拠を説明。
- 編集方針と三言語の更新記録を掲載。専門家監修、公式認定、成績向上、審査合格などを捏造していない。
- 更新日を新規記事ごとに持たせ、既存7記事の日付を一律に新しくしない。
- ブラウザー検証で見つかった静的ゲーム紹介のアンカー不足を修正。

追跡：独自の学習価値 → 学年横断の補助練習 → 数の関係／接続と最小コスト → balance／network → 固定例題と独立練習 → `/{en,zh,ja}/guides/{balance,network}` ↔ `/world?locale=…#game-…` → 採点・独立計算・ブラウザー検証。

学年別の課程、問題生成、採点、解放条件、保存形式、広告同意の挙動は変更していない。既存のゲームを別教材に置き換えていない。
