# 中国本土の小学生向け：課程調査とゲーム大綱の追加

調査日：2026-09-05。状態：研究・設計のみ。実装、問題作成、データベースへの投入、公開は行っていない。

## 1. 対象・根拠・確認範囲

初期対象は中国本土の普通話・簡体字で学ぶ小学生。六三制（小学校6年）と五四制（小学校5年）を別課程として設計する。香港・マカオ・台湾等の異なる教育課程や、少数民族言語・国際学校の個別課程まで対応済みとはしない。中国語を母語として学ぶルートと、追加言語として学ぶルートも分ける。

基本根拠は教育部の「义务教育课程方案和课程标准（2022年版）」。数学については通知に示された2022年5月9日付の差替え版を正式照合先にする。ネット検索に表示される取得日・更新日を、課程の改訂年と取り違えない。

- [教育部の通知と各教科標準への入口](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)
- [上海市教育委員会の正式転載・添付一覧](https://edu.sh.gov.cn/mbjy_fgwx_qt/20220720/02b90de93ebd49099e43063f7a6e2630.html)
- [課程方案PDFの正式転載](https://edu.sh.gov.cn/cmsres/fe/fed40eabbc5d44ba921ae2bdeac22724/45b77003038ffad39ad3924a7cd3a4d6.pdf)：本文6〜9ページの科目設定、表1、表2と注記を画像で確認。
- [教育部教材局の改訂説明](https://www.moe.gov.cn/fbh/live/2022/54382/sfcl/202204/t20220421_620077.html)：低学年の活動・遊び・生活に結び付ける設計、科目の再整理を確認。

一部の教科PDFは取得制限があり、全条項・全教材版を精読したとはしない。下記のゲーム名、学習順、採点方法は本プロジェクトの設計案。厳密な学年・学期・教科書単元の対応は、正式標準と地方の実施・教材版を照合してから承認する。

科目配置と開始年級の根拠は前節の課程方案本文7〜8ページ。科学・総合実践の早期開始、労働と情報科技の独立は教材局の改訂説明でも確認できる。

## 3. 学段別の内容とゲームの発展案

以下は六三制を起点にした編集用の三段階。各欄はその学段の代表的な設計候補であって、全員が同じ学年・同じ学期に学ぶという意味ではない。五四制では段階を単純に1年分削らず、前提目標で組み直す。

| 領域 | 1〜2年を起点とする具体操作 | 3〜4年を起点とする説明・比較 | 5〜6年を起点とする統合・応用 |
| --- | --- | --- | --- |
| 语文 | 拼音、基本の文字・語、絵と短文、順序、音読と意味 | 部首で調べる、文脈語彙、段落、物語・情報文、紹介と手紙 | 複数資料、人物と表現、詩文、構成を考えて説明・提案を改稿 |
| 数学 | 具体物で数と演算、分類、形、長さ・時刻・金銭 | 位取りと乗除、分数小数の導入、角・面積、表やデータ | 分数小数の関係、比・割合、図形の面積体積、複数条件の計画と資料解釈 |
| 科学 | 観察・分類・身近な変化を記録 | 条件を変えた比較、測定、簡単な仕組みを作る | 公平な比較、複数の証拠、モデルや設計を検証して改善 |
| 道德与法治 | 学校生活、順番、安全、気持ちと相談 | 地域の役割、ルールの意味、協力、公共の場所 | 適齢の制度・権利責任、資料による判断、多様な立場の検討 |
| 英语 | 学校で早期実施する場合の聞く・話す活動 | 生活のやり取り、音と文字、短い物語や案内 | まとまりのある理解・表現、目的別読解、文化比較とやり取り |
| 信息科技 | 他教科に関連する安全な操作体験 | 目的に合う情報の整理・共有、手順の表現 | アルゴリズム、条件・制御、試験と修正、出典やプライバシー |
| 芸術・音楽 | 色形・拍・音を試し、表現する | パターン、物語、演奏・造形の工夫 | 意図・使う人・観客を考え、比較・改稿・共同制作 |
| 健康・労働・実践 | 身の回り、簡単な世話、体の感覚、安全 | 作業計画、役割、観察記録、適齢の共同活動 | 調査・予算・工程、使う人への配慮、成果と過程の振り返り |

数学・科学・情報科技の操作案には[教育部「中小学实验教学基本目录（2023年版）」の湖南省教育庁掲載](https://jyt.hunan.gov.cn/jyt/sjyt/jyzbc/zbczcwj/syjx/202506/t20250605_33692362.html)も参照する。これは課程を実践へつなぐ補助資料であり、2022年版の課程自体を置き換えない。

労働は日常生活、生産、サービスという枠組みを参照するが、幼い子に高学年の作業をそのまま要求しない。[2022年版労働標準](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582367012450.pdf)。工具、加熱、電気、薬品を使う現実の課題は安全な大人の支援と別の審査が必要。ゲーム内の並べ替えで実際の技能習得を認定しない。

## 4. 中国語母語ワールドの追加と既存領域の活用

新設はZH01〜ZH06の6系統。詳細仕様は [関門カタログ](LEVEL_CATALOG.md) に置き、二重管理しない。全体は13ワールド・78系統になるが、完成した問題・ゲームの数ではない。

- ZH01 拼音小火车：普通話の音、声母・韻母・声調、音節。
- ZH02 汉字小工坊：筆画・字形・偏旁部首、辞書、文中の意味。
- ZH03 词句小桥：語彙、文、句読点、段落のつながり。
- ZH04 阅读小侦探：物語と情報文、推論、資料の根拠。
- ZH05 诗文小剧场：適齢の詩文、朗読、情景と表現。
- ZH06 表达小作家：話す・書く、目的と読み手、下書きと改稿。

他教科は既存のMA/SC/HU/FL/CT/DM/AR/MU/HW/LSの操作エンジンを共有できる設計とする。ただし問題、正答、学年、課程参照、社会的背景は中国本土用として別審査する。「エンジン共有」を「既存日本語問題の翻訳だけで適合」にしない。

例として算数・数学のかけ算でも、同じ九九の答えを問うだけではなく、等しい組、図との対応、分配や逆算の説明へ分ける。中国版・日本版の同学年を無条件に同じプールへ入れない。

## 5. 中国本土用のミッション例

以下は独自の課題案。学段は設計候補であり、具体的な年級の公開は標準・教材版の照合後とする。

| 課題案 | 候補段階・系統 | 行動と成果 | 採点・支援の注意 |
| --- | --- | --- | --- |
| 文具小商店 | 初期、MA02 / MA05 / LS04 | 元・角・分で予算を考え、複数の買い方を比べる | 通貨をCNYと明示。JPY記号との混同、現実の課金への誘導を避ける |
| 班级图书角 | 中期、ZH04 / ZH06 / MA06 / LS06 | 本の紹介を読み、架空の貸出表を整理し、配置を提案 | 実在児童の名前・借りた本を収集しない |
| 种子观察站 | 初〜中期、SC01 / LS02 | 成長記録と条件を比較し、次の世話を考える | 観察と因果推論を区別し、単一の結果を普遍化しない |
| 校园节水小队 | 後期、MA06 / SC06 / ZH06 / LS06 | データから改善案を作り、比較後に説明を修正 | 計算、根拠、実行可能性を別評価。環境用語の暗記にしない |
| 智能温室小工程师 | 後期、SC01 / CT02 / CT03 / CT06 / DM06 | 条件付きの散水モデルを作り、例外条件でテスト | 初歩の自動制御とAIを混同しない。画面上の模型で検証 |

知識練習は通常10問、同一セッション内の重複を避ける既存方針を維持。日本語のヒントを混ぜず、中国語で段階的に支援する。説明・創作・現実の活動は知識クイズの点数だけで代替しない。

## 6. 教材版・習熟・依存関係

追加する設計項目：`curriculumId`、`schoolSystem`、`educationStage`、`yearKey`、`semester`、`textbookPublisher`、`textbookEdition`、`textbookUnitRef`、`standardReferences`、`alignmentStatus`、`contentLocale`。

- 国の課程 → 地方実施 → 教材版・年度 → 学年・学期・目標を追跡する。版未指定の「課程基準ルート」と、教科書順のルートを区別する。
- 「人教版」「北师大版」「苏教版」等の名称は将来の選択例であり、現時点で対応完了・利用許諾済みではない。目次・本文・図版の収録は権利を確認する。
- 題庫には版番号・年度・簡体字・普通話の前提を持たせる。章番号だけで別版の問題を結ばない。
- 中国語母語、日本語母語、外国語中国語を別の能力証拠にする。日本の漢字1,026字のクリアを中国語の識字完了に変換しない。
- 前提依存は学習目標で定義し、別学年・別地域の同名ノードへ誤連結しない。同じ課程内でも挑戦入口は自由にし、前提未学習は案内や橋渡し課題で支援。
- 五四制の小学校完了を6年分の分母で計算しない。版変更・学制変更でも履歴、購入品、旧達成を残す。
- Profileは課程・学制・コース版で分け、未実装関門を総数に数えない。修了証はゲーム内コース修了であり、学校の卒業資格や教育部認定ではない。

## 7. 中国語・スマートフォン・入口の習慣

「继续学习」「选游戏」「按年级」「我的学习记录」を候補表示とし、既存の4起動画面から本人が選ぶ。教材版・上下学期は学校学習に合わせたいときだけ聞く。氏名・性別・生年月日、学校名、居住地を起動条件にしない。

簡体字の字体・句読点、拼音の声調とü、中文フォント、入力変換中の状態を検証する。部首の分類や筆順は中国語の正当な教材を根拠にし、日本語字形を代用しない。文字入力が難しい子にはタップによる代替を用意する。音声は普通話の品質を審査し、マイクは必須にしない。

上学期・下学期、単元復習、誤概念に沿ったやり直しは選択肢として用意するが、中国の全児童が同じ順番・競争的ランキングを好むとは仮定しない。先に遊び方を選ぶ経路も残す。

中国本土の実ネットワーク、一般ブラウザー、必要に応じてWeChat内ブラウザー等は試験候補。調査時点で対応確認はしていない。現在のGoogle認証、Turnstile、広告、外部フォント・音声等の到達性を地域・回線別に検証し、その成功を匿名の入口表示条件にしない。別の認証・広告・決済サービスへの切替やアカウント開設は今回の作業に含めない。

## 8. 追加のAI・科技教育方針の扱い

2022年課程の情報科技を基礎に、[2025年の科技教育に関する教育部等の意見](https://www.moe.gov.cn/srcsite/A06/jcys_jyzb/202511/t20251111_1419878.html)と[2026年の「人工智能+教育」行動計画](https://www.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html)を追加の確認対象とする。これらを、すべての小学校・学年で同じAI教科・時間割がある根拠にしない。地方の正式実施を確認する。

ゲーム案は、身近な自動処理、分類、手順、データの偏り、AIの誤りと出典確認、人が判断する責任。生成AIを児童の自由入力先として無条件に開放せず、架空・事前審査済みの資料で学べる設計にする。理解度や作文評価をAIの単独判断へ委ねない。
