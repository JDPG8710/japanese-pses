# ログイン入口とゲーム説明（2026-09-06）

## 今回の範囲

- メール登録・ログイン、WeChat登録・ログインは、依頼者の確認により「準備中」の入口のみ追加した。
- どちらも現在は認証要求を送信せず、メールアドレスやパスワードを収集しない。Googleログインと未ログインでのプレイは従来どおり。
- 日本語・英語・中国語で状態を明示する。正式なメール送信サービス、WeChatの審査済みアプリおよび秘密鍵が用意できた後に認証を実装する。
- Cloudflareのメール送信ドメインの読み取り確認は権限不足（2036）で完了していない。サービスや有料プランの契約変更は行っていない。

## ゲーム説明

`src/tutorial/` の共通ダイアログを、日本コース、国際ロジックラボ、国際教科学習の入口に接続した。

- 新しいゲーム・再挑戦・次ステージを開始する際に、3ステップの動く見本を表示する。
- ゲーム中の右上に「あそびかた」ボタンを表示する。結果画面・ホームでは表示しない。
- ×、開始ボタン、Escapeで閉じる。数字ボタンで手動切替でき、自動再生も停止できる。
- OSの動きを減らす設定では自動再生・CSSアニメーションを停止する。
- 本番の問題・正答を説明に渡さない。クイズ、部首、ペア、てこ、回路、月相、仕分け、地図等を実際のゲームクラスで選ぶ。国際ゲームは9種類の操作に対応する。
- 日本のクイズは10問中7問以上、国際チャレンジは10問で800点という既存の条件を表示する。説明機能から点数や通過記録を変更しない。

## 時計とサーバー

日本コースでは開始前の説明が閉じられるまでゲーム本体を起動しない。再表示中はステージ時計とプレイ時間通知を停止し、キャンバス更新を休止する。

国際ゲームでは、匿名プレイはローカル時計を停止する。ログイン中は以下を使い、D1側でも説明時間を除外する。

- `POST /api/world/tutorial`
- `POST /api/foundation/tutorial`
- 入力: `{ id, revision, action: "pause" | "resume" }`
- 応答: `{ expiresAt, paused }`

所有者、Origin、revisionを検証する。説明中の回答を拒否し、停止・再開の再送は残り時間を水増ししない。期限切れや終了済みのゲームを再開できない。通信失敗時は新しいチャレンジを案内し、サーバー時計を無視してプレイし続けない。

## リリース順序

今回はソースとローカル検証の変更。Cloudflare本番への公開時は、必ず以下の順に実施する。

1. `npm run db:migrate` で `0009_tutorial_pause.sql` を適用する（既存結果を削除しない）。
2. `npm run build`。
3. `npm run deploy:worker`、続いて `npm run deploy:pages`。

フロントエンドだけを先行配信すると、ログイン中の説明APIが利用できない。教材データやメール・WeChatの秘密鍵を静的成果物に追加しない。

- `node tests/test_foundation_api.mjs`
