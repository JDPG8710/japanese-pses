# 小镇操作与居民互动

- 交通模式使用步行、汽车、飞机三个 60px 按钮，选择后取消按钮焦点并将键盘控制交还场景。选中状态、三语标签、保存恢复及联机同步沿用原交通状态。
- 小镇页面禁止右键菜单、非输入区拖选与 Ctrl/Cmd+A；输入框仍保留文字编辑。监听器由 AbortController 释放。
- 六种劳作居民：园丁浇花、面包师烘焙、机器人维修、猫画家绘画、钓鱼者、青蛙乐手。具有不同服装、工具、场景道具与手臂动作；原任务角色及奖励不变。
- 靠近至 3.2 单位或碰撞时触发花朵、面包、火花、颜料、飞鱼或音符特效。持续 1.7 秒、冷却 6 秒；保持靠近不反复触发。高空飞机不会触发地面惊喜。
- 所有新居民沿用真实碰撞分离；暂停停止动画，减少动态效果设置抑制飞散和旋转，退出销毁人物、道具和粒子的 GPU 资源。

验证：test:town:interaction、test_town_exploration_browser、test_town_release_browser；覆盖 320/390/1440px、真实键盘移动、实体碰撞、暂停与重复销毁。
