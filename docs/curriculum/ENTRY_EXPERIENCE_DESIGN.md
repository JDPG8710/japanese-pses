# 国際版：選べる起動画面とスムーズな学習入口

作成日：2026-09-05。追加の設計提案。画面順序を変更してよいという最新要望を、[全体設計](GLOBAL_CURRICULUM_DESIGN.md)へ反映する。ゲームの起動コード・公開サイトはまだ変更していない。

## 1. 目的と設計上の境界

目的は、各地域の言葉と学校制度に合った表示で、初めての子も繰り返し遊ぶ子も少ない迷いで学習を始められること。国籍によって「日本の子は学年優先」「米国の子はゲーム優先」と固定しない。

地域ごとの名称は公的資料を確認する。一方、好みの起動画面、説明量、遊び方の選び方は未検証の利用仮説であり、本人の選択と対象ユーザーの観察で決める。国別の行動調査を実施済みとはしない。

追跡鎖：`初回/再訪/教材指定/共有端末 → 起動画面 → 不足設定のみ入力 → 課程・版・学年・学科・目標 → ゲーム型・題庫 → 明示的な開始 → 結果・次へ・保存`。

変えてよいもの：最初の画面、ゲームと学年の選択順、設定済み画面の省略、任意の紹介表示。変えてはいけないもの：目標と題材の一致、児童情報の保護、必要な安全確認、購入時の確認、誤ったクリア・報酬の防止。

## 2. 現状で確認した起動時の制約

| ローカルで確認した処理 | 再設計案 |
| --- | --- |
| `index.html` の初期化末尾で `showLearningModeModal()` を呼ぶ | 保存した入口と有効な再開先を評価し、必要な画面だけ表示する |
| モード画面を開くたびに選択パネルへ戻る | 起動と「選び直す」を別の操作にし、戻った際の選択・スクロール位置を保持 |
| ゲーム一覧→学年選択後、通常入口は第1関を指定する | 「続き」と「最初から」を明確に分け、再開を第1関への強制リセットにしない |
| 紹介は日本時区で1日1回、5秒表示 | ローカル日付で判定し、すぐ閉じられる。次回以降の非表示を選べる |
| 起動で認証・会員状態等の取得を順に待つ経路がある | 最初の選択画面は先に表示できる構成を検討。準備完了前にゲーム開始・報酬処理は行わない |
| 既存入口テストがモード画面と東京時区の文字列を要求する | 実装時に状態別の行動テストへ変更。既存の任意ログイン・進捗契約は維持 |

参照：`index.html`、`tests/test_learning_entry_and_progression.js`、`src/auth/LoginReminderManager.js`。実行時間や離脱率を測定済みという意味ではない。

## 3. 国・地域による表示の調整

| 対象 | 入口の表示と選択項目 | 避けること |
| --- | --- | --- |
| 日本 | 「学年」「教科」「つづきから」。低学年はかな・読み補助。学校順と好きなゲームの両方を用意 | 全員に漢字中心のメニューを見せること |
| 中国本土 | 「年级」「学科」「继续学习」。六三制/五四制、学年、必要に応じ「上册/下册」や教材版を選ぶ。簡体字と漢語拼音を適切に表示 | 日本の配当漢字・科目制限・Googleログイン成功を中国版の開始条件にすること |
| オーストラリア | Year、Maths。Foundationに州・準州の確認済み呼称を併記できる。州設定は関連教材に必要なときだけ | Prep / Reception / Kindergarten等を全州同じ意味で扱うこと |
| ニュージーランド | Year 0〜8の課程範囲を尊重。英語教育課程を明示し、Māoriの表記と長音符を保持 | 日本の6年制への切り詰め、英語版を全言語課程対応とすること |
| 米国 | Kindergarten / Grade、Math。州が未設定なら参照課程であることを表示し、州対応を後から選べる | ブラウザーが英語というだけで米国課程を選ぶこと |
| 英国 | England / Scotland / Wales / Northern Irelandの課程を分け、Year / P等を対応表で表示 | en-GB＝England、またはReception＝日本の1年とすること |

オーストラリアの最初の学校年には地域別の呼称がある。[ACARA 保護者向け説明](https://www.australiancurriculum.edu.au/help/parent-information/what-students-learn-during-the-first-11-years-of-school)

EnglandのReception・Year・Key Stageは[英国政府の案内](https://www.gov.uk/national-curriculum)、NZの範囲は[教育省のYears 0〜8案内](https://www.education.govt.nz/node/1713)を参照する。英国の他地域の根拠は全体設計に記載。米国は教育が主に州・地域の責任であるため、全国同一の細目対応を約束しない。[米国教育省](https://www.ed.gov/about/ed-overview/federal-role-in-education?lang=en)

中国本土の正式課程と入口の補足は [中国本土調査](CHINA_PRIMARY_OUTLINE.md) を参照。教材版・学期は学校に合わせたい場合の任意指定とし、版未指定でも審査済みの課程基準ルートを選べる設計にする。版を選んだ場合は章順が未確認の教材へ自動代替しない。「中国の子は全員教科書順を好む」などの行動仮説を事実扱いしない。

### 言語・国・課程を混同しない

- UI言語の優先順：この操作で本人が選んだ値 → 利用者別の保存値 → 対応するブラウザー優先言語 → いつでも変更できる言語選択。
- `en`だけなら地域中立の英語UIを使う。米国・英国・豪州・NZの課程は自動確定しない。対応言語がない場合は言語名を原語で示す簡潔な選択を出す。
- 言語切替に国旗だけを使わない。「日本語」「English」のように表示する。国籍・住所・生年月日を聞かなくても使えるようにする。
- 選んだ課程と学年はプレイ前に確認可能にするが、国・地域選択を独立した必須の最初の画面にはしない。
- ブラウザーの言語は表示の参考であり、居住地・学力・母語の証明ではない。位置情報や端末指紋で入口を決めない。[W3C 言語選択の説明](https://www.w3.org/International/questions/qa-site-conneg.en.html)
- 日付、数字、通貨は表示地域に合わせる。紹介の「今日」は端末のローカル日付を使い、学年・進捗・報酬の条件には流用しない。学年の自動繰上げは行わない。
- 中国語UIにはzh-Hans-CN、教材には普通話と簡体字を明示。拼音・数字・記号を入力する際は変換確定を待ち、全角/半角等の許容規則を学習目標に応じて定義する。中文表示を選んだだけで中国本土課程に切り替えない。

## 4. プレイヤーが選べる4つの起動画面

設定名案：「はじめの画面 / Start screen」。選択すると小さな順序プレビューを見せる。子どもに多数の画面を自由に並べ替えさせるのではなく、安全なプリセットと任意画面の表示切替を用意する。

| 設定ID | 表示名案 | 次回の順序 | 再開先・設定がない場合 |
| --- | --- | --- | --- |
| CONTINUE | つづきから / Continue learning | 再開カード → 開始 → 前回の目標・ステージ | 簡潔なモード選択へ。勝手に第1関を開始しない |
| GAME_FIRST | ゲームから / Pick a game | ゲーム一覧 → 対応する学年・目標のカード → 開始 | 不足している課程・学年だけ同じパネルで指定 |
| GRADE_FIRST | 学年マップから / My learning map | 保存済みの学年マップ → 学科・目標・遊び方 → 開始 | 課程・学年選択を1パネルにまとめる |
| CHOOSE_EACH_TIME | 毎回選ぶ / Choose each time | 簡潔な入口 → ゲーム優先または学年優先 | 初回の標準設定。ログイン・プロフィールを前置しない |

設定はどの地域でも同じ機能を持つ。国別に隠さない。既存ユーザーは未選択なら現在のモード選択を維持し、「次回はこの画面から」を任意で設定できる。一度ゲームを選んだだけで恒久的な設定変更をしない。

起動設定と別に「紹介アニメを表示」「説明を必要なときだけ表示」を選べる。画面の途中でも上部の「はじめ方を変える」から変更できる。過去に削除した画面下のゲームボタン群やAgent通知は復活させない。

## 5. 利用場面ごとの画面順序

| 利用場面 | 提案する経路 | 省略する画面 |
| --- | --- | --- |
| 初めて・特に目的なし | 言語が読める簡潔な入口 → 遊び方または学年 → 不足項目を含む目標カード → 開始 | 個人情報、ログイン、全機能ツアー |
| 再訪・続きたい | 課程・学年・目標が見える再開カード → タップして開始 | モード、ゲーム、学年の再選択 |
| 再訪・別の遊び方 | 保存したゲーム一覧 → 対応目標カード → 開始 | 設定済みの課程の再入力 |
| 家庭学習・学校の単元に合わせる | 学年マップ → 学科・目標 → 遊び方を選んで開始 | 別モーダルでの重複した確認 |
| 保護者・教師から特定教材のリンク | 教材の課程・目標・概要 → 開始 | ホーム、モード選択、日次紹介の前置 |
| 兄弟・共有端末 | 必要な場合だけ端末内の利用者を選ぶ → その利用者の入口 | 氏名・年齢・性別の再入力。単一利用者なら選択不要 |

ここで矢印は情報の順序を表し、すべてを別ページにする指示ではない。複数候補から選択が必要な場合だけ操作を増やす。対象が一つに確定しているときは重複した選択や確認を省き、開始ボタン付近に現在の選択を示す。

### 初回入口の最小レイアウト案

`ロゴ ＋ 言語切替` → `ゲームから／学年から` → `現在の課程・学年（変更可能）`。

戻ってきた子には一番上に「つづきから」を追加する。大きな主要ボタンは一つ、代替入口は二つまでを設計目安にする。その他の設定・プロフィール・説明は別の場所にまとめる。

「今すぐ遊ぶ」で未確認の日本1年や米国Grade 1を勝手に開始しない。課程・学年が未設定なら、ゲームを選んだ後の一つのパネルで指定する。国籍を聞く必要はないが、学習内容を確定するための選択は省けない。

短い診断を提供する場合は任意にし、受験しないと遊べない構造にしない。学年と推定習熟度を同じ値に書き換えない。

## 6. 入口決定と復元のルール

入口決定の優先順：利用者が今選んだ操作 → 検証済みの教材指定リンク → 保存した起動画面 → 初回モード選択。共有端末で利用者が不明な場合は、他者の記録を表示する前に必要な利用者選択を行う。

- 教材リンクは今回の入口だけを変える。恒久的な起動設定や受講課程を書き換えない。ゲーム内IDと版を検証し、任意URLへ転送しない。リンクだけで本人確認や会員権を変更しない。
- 続きは目標、コンテンツ版、ステージ、問題状態、残り時間の整合を確認。未対応の途中保存なら同じステージのやり直しを説明して選べるようにし、時間や報酬を密かにリセットしない。
- 完了したステージなら、確認済みの次のステージを再開カードに示す。課程末尾なら成果と別の挑戦を表示し、最後の関を再報酬化しない。
- 廃止・未公開・地域不一致の教材リンクや保存先は、その理由と選び直す方法を表示する。別学年へ静かに飛ばさない。
- 開いた画面だけではゲームを自動開始しない。教材・音声等の準備ができ、本人が押した時点で開始する。ダブルタップで二重開始しない。
- 戻る操作は直前の選択、一覧位置、絞り込み、キーボードフォーカスを復元。スタックの一番上からホームへ戻せる経路も用意。
- 課程や学年変更では互換性のない学習目標を選び直すが、変更前の進捗は残す。UI言語だけの変更で学習目標や英語の難度を初期化しない。

保存項目案：`entryPreferenceVersion`、`startScreen`、`showBrandIntro`、`instructionPreference`、`uiLocale`、`curriculumId`、`curriculumVersion`、`yearKey`、`lastRoute`、`lastPlayableStateRef`。

学習者IDと端末モードを単位に保存し、兄弟間で混ぜない。共有端末では恒久保存しない選択も用意。ローカル保存が使えない場合はそのセッションだけで機能させ、起動を妨げない。クラウドへの設定保存は任意ログイン後とし、別端末の設定が現在開いている画面を突然切り替えないようにする。

## 7. 紹介、ログイン、プロフィール、広告の順番

| 要素 | 改訂後の設計 |
| --- | --- |
| ゲーム名の5秒紹介 | 名前は背景と入口に常時置く。紹介は標準でローカル日付の1日1回、すぐ閉じられ、非表示を保存可能。操作部分を覆わない形を優先。再開・教材指定を妨げない |
| 個人情報 | 名前・年齢・性別は後から。既存の「まなびくん」を無入力開始に使い、地域向けの中立表示名は翻訳レビュー後に用意 |
| 操作説明 | 新しい操作が初めて必要になる時点に短く表示。「もう知っている」で閉じられ、ヘルプから再表示可能 |
| Googleログイン | 任意の保存・同期として扱う。未ログイン5分の既存リマインダーは実プレイ累計と安全な区切りを維持。起動画面の変更で前置しない |
| 広告・会員案内 | 起動・言語選択・復元中の待ちを広告用プレイ時間にしない。今回の設計で広告間隔、課金額、会員権は変更しない |

ログイン、報酬、広告、プロフィール等が同時に表示されないよう、実装時に表示の待ち行列を設ける。プレイ中・開始準備中は任意の表示を割り込ませず、安全な区切りで一つずつ扱う。待ち時間分の通知をまとめて連続表示しない。途中で必要な安全説明や確認を「流れの短縮」のために削除しない。

任意のステップには任意であることとスキップ方法を表示し、複数段階では現在位置と戻り方が分かるようにする。[W3C WAI 複数ページのフォーム](https://www.w3.org/WAI/tutorials/forms/multi-page/)

## 8. 低性能端末・タッチ・読みやすさ

- 選択画面と既存保存値を先に表示し、必要な教材・一つのゲームだけを準備する。全78系統や全地域教材を起動時に読み込まない。
- ネットワーク応答待ちは状態と再試行を示す。認証・会員権・保存ユーザーが不明なまま別ユーザーの進捗を使って開始しない。必要なら匿名オフラインで遊ぶかを明示的に選んでもらう。
- 小画面は1列、大きな開始ボタン、伸びるカード、折返しを基本にする。ホバーに依存しない。国/課程設定は下部シートなどでまとめ、複数の重なるモーダルを作らない。
- 英語の長い教科名、Māoriの表記、200%文字拡大でも内容が切れない。固定高さや文字サイズの自動縮小で帳尻を合わせない。
- 低年齢は56px、他は44px以上のタッチ目標を設計目安とし、色と記号で選択を示す。キーボード操作とフォーカス順を見た目の順序に一致させる。
- 低モーション設定では動く紹介を静止ロゴにする。音声の自動再生、画面回転の強制、フルスクリーンの強制をしない。

## 10. 「スムーズ」の確認方法

目標値は測定結果ではない。再訪の有効な再開は1タップ、設定済みゲーム優先は2〜3回の主要操作を設計目標にする。初回の言語・学年等の入力を数から除外して「全員2タップ」と宣伝しない。

初回表示から最初の有効なゲーム操作までの時間、必要操作数、戻り直し、誤課程開始、設定やり直し、再開失敗を測る。問題正答や個人の優劣と混同しない。自動収集をこの文書追加だけで有効にしない。
