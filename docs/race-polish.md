# 皮可环道：操控与场景打磨

## 需求与追踪

修复反向转向、改善高速弯道操控，并提供有空间层次的赛车环境。
用户目标 → 无年级/学科（独立休闲街机） → 驾驶操作 → arcade:race → 4 条赛道 / 4 类车辆 → world.html 街机入口、town.html 赛车建筑 → 操控回归与浏览器截图。
课程题池、学习路径与奖励契约不在本次改动范围内；赛车仍采用三圈、生命值与原有道具/AI。

## 改动

- RaceGame：+Z 前进坐标系下，追尾视角的左转应增加 heading，原实现符号相反。统一修正 A/D、方向键、触控与外部控制；加入转向插值、低速转向约束、高速转向保留、较平缓加速、帧率无关镜头与正确初始镜位。
- 输入：使用物理按键 code，兼容非拉丁键盘；失焦、切页、暂停清除输入。触控按 pointerId 管理并捕获指针，支持油门/转向双指独立释放。
- RaceScenery：连续路面网格、沥青颗粒、红白路肩、车道线、护栏、软阴影、渐变天空、云层和雾化远景。林地/山地植被地形、港口海面/集装箱/船舶/吊机、夜景楼群与路灯均为实时三维/程序化资源，无外部素材请求。
- RaceCars：倒角车身、斜面玻璃、轮胎轮毂、车灯、后视镜与转向轮动画。
- RaceTracks：港口原八字路径出现急弯内侧路面折叠，并与“宽弯”说明冲突；改为无交叉的宽弯港口环线。
- 生命周期：重建和退出释放几何体、材质、纹理、实例缓冲与阴影资源。重复景物实例化，像素倍率沿用共享渲染器上限。
