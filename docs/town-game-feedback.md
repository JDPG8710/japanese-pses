# 小镇游戏内反馈修复

## 需求追踪

英语选择图像答对后没有游戏内反馈 → 现有独立难度（不改年级映射） → 英语词图对应 → runner 英语传送门 → 原题池与当前关卡 → town.html 的英语建筑 → 真实移动进入正确门、场景内成功提示和动画。
同一路径审核扩展至 obby 数学跳岛、tower 算术攀塔、memory 英语颜色记忆、garden 双语农场；保留各自学科、题池、难度、存档与奖励规则。

## 根因与修改

五类学习游戏共用 TownExpansion.choose：成功时只写入侧栏 .arcade-feedback 并停止角色输入，没有触发场景动画。全屏和手机游玩时，反馈因此脱离视线。

- 删除侧栏结果段落。GameFeedback 在 .scene-viewport 内呈现成功、奖励及解释，辅以星光动画；下一关操作继续留在游戏内。
- TownScene3D 在正确目标处播放光环与粒子，并高亮正确标签；第一人称也有视口提示。
- memory 每个正确步骤仅显示进度鼓励；整组完成才显示通关与实际奖励。错误、坠落、机会耗尽使用重试提示，不播放成功粒子。
- 进入下一关、重试、退出和重建场景清理反馈与 GPU 资源。重开已通关存档显示静态结果，不重新发奖或重播庆祝。
- 提示避开按钮，随控制区换行调整位置；支持 prefers-reduced-motion 和读屏 status。
- 审核其他游戏：水果、打砖块、打字忍者、赛车已有游戏内粒子。共享 ArcadeShell 新增仅通关时播放的结算动画。
- 原商店的反馈已位于游戏对话框内，补充正确操作动画；保留原流程及错误辅助。

## 验证

- test_town_feedback_browser.mjs：五类游戏桌面实操，390px 英语、320px 记忆，第一人称、全屏、减少动态效果、按钮避让、错误无奖励、记忆中间步骤无奖励、下一关和退出清理；截图位于 .wrangler/town-feedback/。
- test_town_3d.mjs：五种模式 × 九种难度组合 × 120 关等规则/奖励/恢复检查通过。
- test_town.mjs：原故事、购物与装修规则九组通过。
- test_town_3d_edges.mjs：七组真实浏览器边界验证通过，包含护盾、坠落、提示、装备后跳跃及记忆重播。
- test_platform_course.mjs：1440 个可复现关卡、112520 次跳跃验证通过。
- test_arcade_smoke.mjs、test_race_browser.mjs：街机启动及共享结算成功/失败样式检查。
- test_e2e_runner.js：44 组、212 项通过；构建通过。

本次为本地实现；手机检查使用 Chrome 触屏模拟，尚未发布线上。
