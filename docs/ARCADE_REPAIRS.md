# 打砖块与水果风暴修复

2026-10-03：砖阵的侧面及后方保留球体通行间距，所有 1–20 关可完整消除。球采用连续碰撞检测、接触后分离与最低纵向速度，球拍最边缘的反射角也受到限制，避免近水平长时间撞墙。手机以正交 3D 视角完整显示砖阵、球拍和边墙。

水果新增苹果、橙子、梨、西瓜、草莓、菠萝的程序化果皮纹理与平滑模型，以及果肉切面、叶片和果汁效果。小、中、大水果基础分为 30、20、10；小水果较难命中，基础奖励较高。每次切割另获 2–10 连击加分。

四种炸弹：普通扣 1 命，尖刺扣 2 命，时间炸弹扣 5 秒，冰冻暂停刀刃 1.2 秒。不同造型提示不同效果。每局倒计时 55 秒；计时采用实际帧间隔，低帧率不会延长游戏，暂停不计时，提前通关仍按统一小镇规则奖励。

炸弹命中增加 0.72 秒的爆炸核心、扩散冲击环、烟雾/冰雾、碎片和效果文字。四种炸弹有独立的低音爆破、噪声冲击及时间/冰晶提示音，接入现有 SFX 和静音控制。致命命中立即停止玩法，保留爆炸动画直到结束再显示结算，退出会清理动画资源。`npm run test:fruit:bombs` 在实际浏览器验证四类命中、音频信号、静音、效果过期，以及最后一次爆炸先于结算。

`npm run test:arcade:repairs` 验证所有 20 关完整消除、连续碰撞与角度防卡死、六种水果/三档积分/四种炸弹效果、倒计时与暂停，以及最高难度可在时限内完成。构建后运行 `npm run test:arcade:repairs:browser`，在 1440/390 像素下通过实际发球、球拍移动、滑动切果、超时结算与模型贴图检查。总回归 216/216。
