# 全球学习首页

首页以全球学习路线为主入口；Piko 小镇是课程卡片之后的独立 banner。根路径及中、英、日静态入口均包含课程链接，静态内容不依赖 JavaScript。

## 内容与路由

- 中国、日本、美国、英国、澳大利亚、新西兰及国际通用练习共七个入口。
- 学年地图标注为已开放的补充练习，不承诺完整国家课程或跨国年级等价。
- 日本入口继续使用现有 `/?course=jp` 日本小学课程，标注日语教材原文。
- 其他入口进入 `/grades`，保留独立 `locale`；国际练习显式指定 `curriculum=INT`。
- 学制选择开放所有现有学制；居住国家仅提供默认建议。
- 课程地图的界面语言控件保持当前国家、学制及学年参数。课程原文语言由学习目标决定，不能将界面翻译视为教材翻译。
- 原国家地球入口 `/?choose-country=1&locale=zh` 保留，选择国家不会改变界面语言；设备保存记录也保留用户的语言选择。
- 继续学习入口复用原有设备学制、学年与关卡记录，没有新建账户进度契约。

## 维护与验证

`src/location/HomeContent.mjs` 是首页核心三语内容及路线卡片模板。更改时应同步根页面和 `en/index.html`、`zh/index.html`、`ja/index.html` 的静态内容，保持无 JavaScript 入口可用。布局由 `css/global-home.css` 控制。

`tests/test_town_home_browser.mjs` 验证三种语言、320/390/1440 像素宽度、课程优先布局、小镇 banner、实际小镇加载与回首页、无 JavaScript 本地化入口、国家与语言独立选择及学制跨国选择。现有课程路径、公开内容、SEO、资源版本及发布门禁继续适用。
