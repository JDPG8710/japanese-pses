# AdSense コンテンツ改善記録（2026-09-21）

## 対象と判断

対象は利用者が確認した https://piko-game.com/。提出された画面は「有用性の低いコンテンツ」というサイト単位の不承認通知。具体的な違反URLや内部判定の詳細は表示されていないため、原因を一つに断定しない。

Googleの公式説明は、利用者に関連する独自の内容、使いやすいナビゲーション、良い利用体験を重視している。

- [AdSense: サイトのページを準備する](https://support.google.com/adsense/answer/7299563?hl=ja)
- [AdSense: サイト管理と審査](https://support.google.com/adsense/answer/12131223?hl=ja)

記事数や文字数を増やすだけで承認されるとは判断しない。本変更は確認できた内容と導線の改善であり、承認を保証しない。

## 確認結果

- 本番の `/`、`/world`、`/robots.txt`、`/ads.txt` はHTTP 200。
- robots.txtは公開ページのクロールを禁止していない。
- ads.txtの `pub-8738651569097071` はホームのAdSenseアカウントと一致。
- ホームの説明は短く、多言語紹介ページは理念中心。ゲーム外で手順や解答理由を読める入口を改善できる。
- 既存のプライバシー・利用規約・問い合わせ先は存在する。問い合わせ先を捏造せず、既存の `/privacy#contact` に導線を追加。
- 本番の量水ゲームで、必要な保存だけを選び、ゲストで開始し、遊び方の確認後に問題画面へ進めることを確認。ログインや任意広告の許可は不要。
- 最初のブラウザ検証では教程の確認を待たずタイムアウトした。実際の開始手順を確認して再検証し、正常に通過した。

## 今回の変更範囲

- `en/learning-guide.html`、`ja/learning-guide.html`、`zh/learning-guide.html`：数独の排除、ロボットの最短経路、量水の状態遷移を説明するオリジナル例題。答え、理由、つまずきへの声かけ、家庭での振り返り、訂正窓口を掲載。
- `css/learning-guide.css`：スマートフォンとデスクトップで読めるガイドの表示。
- `index.html`、`src/location/home.css`：ホームに例題、解説、三言語のガイド入口と問い合わせ導線。フッターの文字色も調整。
- `en/index.html`、`ja/index.html`、`zh/index.html`：ナビゲーションと本文から対応言語のガイドへリンク。
- `sitemap.xml`：ガイドの正規URL、言語別リンク、変更した紹介ページの更新日。

ガイドはJavaScript、ログイン、Cookie同意なしで読める静的HTML。広告コードや既存の同意・保護者ゲートは変更していない。既存ビルドが各言語フォルダーとCSSをコピーするため、ガイド用のビルド変更は不要。

## 公開と再審査

この作業では本番配備・AdSense管理画面からの再審査送信を行っていない。作業開始時から別件のゲーム改修が未コミットで存在し、作業中にも別の変更が加わっている。通常の全体配備はそれらを含むため、公開対象を確認する。

公開後、三言語ガイド、ホームからのリンク、CSS、サイトマップを本番で再確認する。AdSenseの「サイト」で対象ドメインを開き、修正した内容とサイト状態を確認して、画面で利用可能な再審査の操作を行う。ボタン名や再申請可能日は実際の管理画面に従う。アカウント内の追加通知と審査結果は別途確認が必要。

## 第二轮改善：实际问题与修复（2026-09-21）

用户要求继续改善，并确认运营者介绍仅使用 Piko Game 品牌。没有添加人员履历、机构认证、审核通过率或学习效果承诺。

### 已确认的问题

1. 线上 `/adsense-audit-missing-20260921`、`/en/does-not-exist-20260921`、`/404.html` 均返回首页与 HTTP 200。不存在的地址会被误当成普通首页。
2. `/world`、`/grades` 的原始主内容区域为空，交互模块加载失败后缺乏可阅读的说明和其他入口。
3. 68条学年路径均显示没有活动的美术、音乐分类，部分路径还显示空的英语分类，点击后只出现准备中提示。
4. 多语言介绍页的装饰圆形在320px屏幕上造成横向溢出；深色游戏页的底部帮助链接对比度偏低。

### 已实施的改动

- 新增 `404.html`，使用 Pages 原生404行为，返回错误状态并提供恢复导航；页面不索引、不加载广告。构建明确包含该文件。
- 为逻辑游戏、学年选择、具体课程页增加无需脚本就能阅读的初始内容与学习指南入口。交互模块成功加载后替换为原有游戏界面；没有针对爬虫展示不同内容。
- Playroom补充围棋与国际象棋的入门说明。网站页脚加入三语指南与帮助链接。
- 学年分类仅呈现当前学年实际包含活动的学科，不改动已有进度、解锁规则或题目。
- 新增 `/about`：三语功能介绍、题目生成方式、适用范围、家长使用提示、故障处理与真实联系邮箱。仅使用用户授权的品牌名称。
- 修复装饰图形溢出，改善深色页脚链接可读性。
- 更新实际修改页面的站点地图日期，加入 `/about` 和已有的 `/updates`，不把404或参数化课程壳加入站点地图。
- 增加 `preview:content`、`test:content`、`test:content:browser` 命令。预览使用 Wrangler 自带 Pages 资源处理器，因此检验的是 Pages 的路由、重定向和404行为。

### 验证证据

- `npm run build` 成功，411个配信文件。
- 15个站点地图地址均通过本地 Pages 资源处理器返回200；不存在的根路径、语言子路径、深层路径和资源路径返回404。
- `.html` 地址正确重定向到无扩展名的公开地址。
- 页面正文、内部链接与锚点、无JavaScript阅读、320/390/1280px布局通过。
- 九种逻辑游戏的游客启动，以及日文、中文教程通过；美国和中国学年中每个可见分类都有活动。
- SEO、隐私选择、68条学年路线及解锁回归通过。
- 完整逻辑游戏回归通过89,654项检查，包含1,800轮生成、18,000道题、临时D1数据库与排名API。
- 首次完整逻辑测试被本机esbuild目录访问限制阻止；允许本地测试进程后重新运行通过。没有因此修改游戏规则或降低测试要求。

这些结果来自本地发布产物和回归测试，不能表述为线上已经修复。尚未部署本次改动，也未操作AdSense账号提交复审。发布时需保留工作区其他游戏改动的归属，确定本次公开范围。

## 第三轮：按缺陷优先级实施（2026-09-21）

用户明确选择“先完成本地修改和验证”。本轮没有部署，也没有提交AdSense复审。

### 已完成

1. **知识与描述准确性**：国际象棋中文说明由“吃掉国王”改为“将死”；科学单元的“能量与模型”标题改为其实际题型“实验条件与证据评价”。42个单元提供三语具体学习目标，接入学年卡片、课程开场和覆盖目录；语言练习仍明确实际学习语言。
2. **可独立使用的内容**：编写七个主题的中英日指南，共21篇。包括数独、机器人寻路、量水、数数、凑十、分数、小镇商店。每篇有前提知识、完整例题、逐步推理、常见错误、独立练习与答案，使用可阅读的棋盘、状态表和等分图。三个语言资料库汇总这些指南。
3. **课程范围可核对**：三个语言目录列出68条学年路径的实际单元及逻辑活动，从现有课程数据生成，避免另抄一套表格导致漂移。明确属于辅助练习，非完整国家课程，也不以学年标签宣称等效或认证。
4. **出错时学到什么**：数独重试时指出重复数字所在行、列或小宫；机器人首次撞墙/越界即时指出第几步及此前坐标；量水显示提交后的A、B水量并解释转移量。诊断只使用题目和用户提交，不提前调用解题器。20以内加减法的解析补充凑十拆数或逆运算验证。
5. **真实入口与维护**：指南链接接入游戏卡片、单元卡片、课程开场、小镇页脚及首页。构建生成27个静态页面（21篇指南、3个资料库、3个覆盖目录）及相互匹配的canonical、hreflang和站点地图项。原有简明指南保留，链接到详细例题。
