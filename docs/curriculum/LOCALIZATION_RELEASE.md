# 分年级基础练习与多语言发布追踪

用户要求：落实此前缺失的基础题语言适配，并发布 Cloudflare。

验收链：国家/学制 → 明确学年 → 学科 → 基础学习目标 → 独立题池 → 10题会话 → 分级提示/结算 → 同一路径返回 → 按该路径保存排名。

本次增加独立的基础练习模块，保留日本原课程及既有5款操作游戏。数学、母语、科学分别有逐级题池；不把两档自由游戏当作全年级题库。题目、说明、错误辅助和结算均本地化。课程选择与界面语言分离，英语母语题和汉语母语题分别编写。区域年级配置为明确的编辑推荐，不宣称各国同数字年级等价或覆盖正式课程全部目标。

课程参照：既有 GLOBAL_CURRICULUM_DESIGN.md、CHINA_PRIMARY_OUTLINE.md 和 LEVEL_CATALOG.md；2026-09-05 复核教育部2022课程通知、英国小学数学课程与 Cloudflare 发布文档。实际题池清单见 FOUNDATION_COVERAGE.md。

迁移只新增练习会话表和索引。原账号、原课程进度、原榜单不覆盖。新榜单按学制、学年、学习目标、学习语言和题库版本隔离，访客可看，登录用户由服务端判题后保存。
