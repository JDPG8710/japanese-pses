# Piko Town 3D · 手动闯关版

本版本将小镇的主要画面从 Canvas 2D 替换为 Three.js / WebGL 2 真正的三维场景：透视镜头、光照与阴影、立体建筑、可旋转视角、模型角色、重力跳跃和平台落地。界面与任务对话仍采用可访问的 HTML。

## 本地启动

```sh
npm ci
npm run preview:town:3d
```

打开 `http://127.0.0.1:4190/town?locale=zh`。仅监听本机。该静态预览不连接现有线上 API；小镇和学习群岛完全在本地运行。

测试最终构建：

```sh
npm run build
node scripts/preview-town.mjs --built --port=4191
```

打开 `http://127.0.0.1:4191/town?locale=zh`。本地服务器读取最终构建目录。正式发布地址为 https://piko-game.com/town?locale=zh 。

## 操作与玩法

- 方向键 / WASD 移动，空格跳跃。拖动场景旋转镜头，滚轮缩放，镜头按钮和跳跃按钮支持触屏。Q 旋转视角，R 重置镜头，V 或视角按钮切换第一人称／第三人称。视角选择会保存。
- 小镇保留皮可、米娅、诺亚以及第一章全部十项委托。沿南侧道路进入游戏街区，走进五座游戏建筑选择玩法；第六座建筑提供道具商店。页面下方不再提供游戏菜单。
- 数学跳岛：随机平台大小、间隔、走向与高度，必须亲自跳跃并实际落到正确答案的平台。
- 算术攀塔：在随机宽窄、高度差和路线的上升台阶之间跳跃，落在正确答案处。
- 英语传送门：识别英文要求，跳过横向移动障碍，进入对应图案的门。
- 记忆地板：先观看英文颜色序列，再依次踏上对应地板；重复颜色之间有明确闪烁间隔。
- 双语农场：读取英文收获订单，计算每篮数量与总数，走到正确的作物地块。
- 游戏中的答案只显示为文字标签。已删除所有小游戏的答案带路、点击场景移动和自动跳跃。小镇内去 NPC 的导航保留。五种模式分别保存关卡，可随时离开、重载和继续。
- 地图由存档种子、模式和关卡生成。每一关重新变化，同关重试保持布局，方便练习。关卡上升会缩小平台、增加路线长度；所有生成范围均按基础跳跃能力验证。
- 题目单独显示在画布上方；场景答案使用至少 22px 的标牌，并用连线指向对应目标，避免远处文字难读。
- 小镇首帧时间差限制为非负数，角色处于地面以下或出生数据异常时会恢复到有效地面；浮空关卡仍保留正常掉落惩罚。
- 手机可一指按住方向键、另一指按下跳跃；跳跃在按下时立即响应。
- 各模式持续按种子和关卡生成题目，没有预设通关终点。数学与英语难度分别设置，新难度从下一关生效。
- 六种免费角色：探险家、机器人、猫咪、宇航员、青蛙队长、建造师。角色预览可拖动旋转，选择反映在实际三维场景中。
- 冒险商店：运动鞋增加速度，弹跳靴提高跳跃，背包与王冠改变外观，护盾自动保护一次错误或掉落，提示卡提供解题说明。使用游戏内星币，无真实货币支付。

## 存档与范围

沿用 `piko-town-v1` 存储键，在旧存档上增加经过校验的 `expansion` 数据。第一章任务、金币、装修保留。五座岛有独立种子、关卡、挑战机会、最高记录和完成标记；同一关已领取的奖励不会在刷新后重复发放。

当前是单人本地存档，不提供联机或设备间同步。Three.js 0.180.0 及其 MIT 许可证随仓库分发，游戏不使用 CDN。需要支持 WebGL 2 的浏览器。加载完成后可断网继续玩；不是离线首次加载/PWA 安装包。

## 设计来源与实现

参考 [Roblox 官方游戏榜单](https://www.roblox.com/charts)中的障碍闯关、攀塔、经营等玩法类型，将游戏目标转换成数学、英语与工作记忆练习。本项目采用自制积木风场景和角色，不导入 Roblox 游戏代码或素材。

- `src/town/TownScene3D.mjs`：三维场景、相机、输入、重力、平台、障碍与玩家输入。
- `src/town/PlatformCourse.mjs`：确定性随机地图、共享重力落地规则与落地判定。
- `src/town/Models3D.mjs`：自制几何角色、建筑辅助、预览及资源释放。
- `src/town/ArcadeRules.mjs`：可重复生成的题目、独立进度、奖励、商店和存档验证。
- `src/town/TownExpansion.mjs`：建筑大厅、游戏 HUD、角色与商店界面。
- `src/town/ArcadeText.mjs`：中、英、日三语言内容。

引擎接入依据 [Three.js 安装说明](https://threejs.org/manual/pages/installation.html) 和 [WebGLRenderer 文档](https://threejs.org/docs/pages/WebGLRenderer.html)。

本次代码在 `codex/learning-town-3d` 分支开发和提交，避免混入另一任务尚未发布的 AdSense 页面修改。
