# 中国与英语小学学年闯关实现

实现日期：2026-09-05。

## 校正后的需求

国际入口不能只提供五款自由小游戏或一组平铺的 10 题练习卡。中国与英语小学入口需要与日本版一致具备“选择学制与学年 → 学科世界 → 有顺序的关门 → 通关记录 → 解锁下一关”的年级冒险骨架，同时使用本地母语内容与各自的学年标签，不把日本题库翻译后冒充当地课程。

追踪链为：

`国家入口 → 地区学制 → 学年 → 学科世界 → 学习目标 → 知识任务／操作游戏 → 10轮关卡 → 800分通关 → 同学科下一关`

## 实现范围

- 中国：六三制 1～6 年级、五四制 1～5 年级；母语关卡使用独立中文题库。
- 英语小学：美国 K～G6、英格兰／威尔士 R～Y6、苏格兰／北爱尔兰 P1～P7、澳大利亚 F～Y6、新西兰 Y0～Y8，以及明确标注的国际通用 G1～G6。
- 每个学年按数学、母语、科学、编程、图形艺术、音乐生成自己的冒险地图，并增加明确标注为补充训练的脑力训练舱；只显示该学年已映射的目标。
- 年级知识任务和 Piko 操作型游戏放在同一条学科路径。数学、编程、语言、科学和脑力训练会按年级穿插管网、数独、密码、集合、方程、排序、量水和电网等操作挑战；低龄基础学年只开放管网、集合与排序三项适龄玩法。
- 每个学科的第一关可直接进入。800/1000 且未超时才记录通关并解锁同学科下一关；失败、超时和 0 分不解锁。其他学科的第一关和其他学年仍可自由选择。
- 旧版基础练习成绩继续被识别；新成绩写入统一的学年冒险进度键。关卡结果页可进入同学科下一关或返回原学年地图。
- 数字题提供 56px 以上的屏幕游戏键盘；语言与科学使用主题化卡片场景。题目仍保持每局 10 题、局内去重、题目与选项独立随机、三次分级提示和 3 分钟时限。
- 国家首页的主按钮进入所选地区的年级冒险；自由选八款小游戏保留为次要入口。日本仍进入原有日本小学星图。

## 课程边界

这些地图是按学年标注的补充学习路径，不宣称完成了各国全年、全科教材或获得官方课程认证。美国各州、英国四教育体系和其他国家不能被合并为一个“欧美统一课程”。界面明确显示所选学制；国际通用练习不冒充国家课程。

- `node tests/test_grade_journey.mjs`：验证所有 68 个地区学年地图、关门去重、学科内解锁、旧进度兼容和路由。
- `node tests/test_grade_paths.mjs`：验证学制范围、年级标签和无效跨学制路线。
- `node tests/test_foundations.mjs`：验证 1,002 个本地化学习路径、题池、10 题去重、答案、提示和课程隔离。
- 真实浏览器：检查中国六三制一年级中文地图、语文卡片关卡、数学触控键盘和适龄逻辑舱；检查美国 Grade 1 英文地图与 375×812 手机布局。新版八款逻辑游戏另按 `WORLD_PLAY_IMPLEMENTATION.md` 的实机记录验收。
