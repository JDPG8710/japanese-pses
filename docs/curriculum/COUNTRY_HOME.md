# IP语言与3D国家选择首页

2026-09-05，已实现本地版本，尚未发布线上。

## 最新需求与路径

首页 → IP推测国家／恢复手选国家 → 3D地球点击或国家列表选择 → 对应学制与语言的学年闯关地图。八款自由小游戏保留为次要入口。

- JP → 日语；CN → 简体中文；其他国家／地区 → 英语。
- 手动保存的国家优先于下一次IP推测，异步IP响应不能覆盖已发生的手动选择。IP未知时使用英语，等待用户选国。
- `GET /api/location` 只读取 Cloudflare 提供的 `request.cf.country`。Pages入口直接处理，Worker保留同一路由；不依赖服务转发后地理元数据是否保留。
- 不使用GPS、不调用第三方IP查询服务、不返回或保存原始IP；响应禁止共享缓存，不读取客户端伪造的国家头。
- 日本主入口进入原日本小学星图；中国与英语地区主入口进入各自学制的学年闯关地图。首页展示地球时不启动任何课程、进度和弹窗初始化；不同地区的同名学年不被视为国际等价关系。

## 地球与选择

Natural Earth公共领域1:50m国家边界随站点发布。242个地图区域，其中239个区域带国家代码、合并重复代码后237个列表选项。国家名称通过本机CLDR/Intl数据使用各地区主要本国语言显示，与当前界面语言无关（如日本、中国、Deutschland、España、대한민국、Brasil）。多官方语言地区使用CLDR推断的主要语言名称。

地球使用球面坐标、正射投影、背面剔除、边缘裁剪和光照呈现3D球体；拖动与按钮可旋转，点击球面通过逆投影判定实际区域。键盘方向键旋转、回车选择球心位置。列表可选择小岛等不易点击的区域，地图文件加载失败仍保留完整代码列表。

坐标使用CSS像素，Canvas根据DPR放大，点击命中不使用物理像素。只在交互／尺寸变化时绘制；退出时移除监听、动画帧和尺寸观察器。
