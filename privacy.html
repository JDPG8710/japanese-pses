PRIVACY NOTICE

How Piko Game handles information

Piko Game is an educational game for primary-school learners. Playing does not require an account. This notice describes the service as of 10 September 2026.

Information kept on the device

The selected country or region, interface language, learner nickname, age band (not a precise age), optional gender (off by default / skippable), game progress, settings, privacy choice, parental acknowledgement timestamp/version, and practice results may be stored in the browser (IndexedDB / localStorage). Clearing site data removes this local information. The connection country is used only to suggest a starting choice and is not added to a server profile by that suggestion alone.

What we collect (field list)

  • Necessary: country/language preference; learning progress; OAuth security cookie (short-lived); signed-in session cookie (up to 7 days); privacy-choice record (up to 180 days); parental-gate acknowledgement version/time.
  • Learner profile (optional): nickname (filtered), age band enum (`under_6` / `6_8` / `9_11` / `12_14` / `prefer_not`), optional gender. Precise age integers are not stored for new profiles.
  • Optional sign-in: Google account identifier, display name, email for authentication and cloud saving.
  • Cloud state (D1): profile summary above, progress, scores, attempts, rewards, certificates.
  • Payments (if enabled): Stripe checkout/payment identifiers and membership result — not full card numbers.
  • Arena: nickname, avatar, visibility flag (default off), tutorial progress, game moves/results; optional report/block records.
  • Advertising: none by default. Optional Google child-directed non-personalised ads only after consent and parental gate, and never under CN safe mode or EEA/UK/CH without a certified CMP.

Cookies, local storage and your choice

Necessary browser storage supports security, a sign-in you request, country and language choices, sound settings and learning progress. Google advertising code is optional and is not loaded unless a parent or guardian passes the parental gate and selects “allow optional ads”. If allowed, Google may use cookies or similar storage to provide and measure child-directed, non-personalised advertising. You can withdraw or change that choice at any time. Advertising remains disabled for visitors in the EEA, the United Kingdom and Switzerland until a Google-certified consent platform is configured. When China safe mode is active, ads are not loaded.

Optional sign-in and cloud saving

If a parent, guardian or other eligible user chooses Google sign-in after the parental gate, Piko Game receives the Google account identifier, display name and email address needed to create and secure the account. Cloud saving can also include a learner nickname, age band, optional gender, progress, scores, attempts, rewards and certificates. Graduation certificates default to a desensitised display name (for example 「学習者」); revealing the real nickname and sharing the certificate number require a parental gate and confirmation. There is no public proof URL—share is number-only. A secure session cookie lasts up to seven days. Public rankings use only a system-generated explorer name and score; they do not display a real name or email address.

How to delete

Local: clear this site’s browser storage / site data.

Cloud (signed-in): open “わたしの学習きろく”, then use クラウド学習資料を削除, which calls DELETE /api/state. That delete covers the signed-in account’s learning tables mainly: user_profiles, node_progress, and game_attempts. After a successful cloud delete, the app clears or prompts to clear the matching local sync cache (IndexedDB / StorageAdapter). It does not delete memberships (ad-free purchase records). You may also email the contact address below to request account-data help. Signing out revokes the session cookie.

Payments, advertising and security providers

If paid membership is activated and allowed in the region, Stripe processes payment details. Piko Game stores payment event and checkout identifiers and the membership result, but not full card numbers. With the optional advertising choice and parental gate, Google AdSense may serve non-personalised ads. The site marks ad requests for child-directed and under-age treatment, and does not enable personalised advertising or remarketing. Cloudflare provides hosting, D1 storage, security and Turnstile bot protection and may process IP address, device and request information for those purposes. Turnstile is loaded only when a user opens the sign-in flow.

Why information is used

  • to provide games, save progress and show rankings;
  • to authenticate accounts and prevent fraud or abuse;
  • to provide membership and payment support where enabled;
  • to operate, troubleshoot and secure the service;
  • not for behavioural advertising by default.

Piko Game does not sell personal information.

Children and family choices

Children can play without signing in. A parent or guardian should manage any privacy choice, sign-in, cloud profile, purchase or public multiplayer for a child and should avoid entering a child’s full legal name. Gender is optional and not required. Requests to access, correct or delete cloud account information can be sent to the contact address below.

Service providers and international processing

Google, Cloudflare and Stripe process information under their own privacy terms and may process it in countries outside the user’s country. Only information needed for the functions described above is shared with them.
