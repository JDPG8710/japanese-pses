# Piko まなびタウン 第1版

公開URL: `https://piko-game.com/town?locale=zh`

## 内容

固定視点のCanvasによる小さな町。広場のピコ、お店のミア、おうちのノアを訪ね、10個のお仕事で開店までを体験する。

- キーボード、地面のタップ、方向ボタン、目的地への自動案内。
- 英語の注文を聞く・読む、商品をそろえる、合計とおつりを計算する。
- 算数3段階と英語3段階を独立設定。進行中の注文は設定変更で変わらない。
- 仕事ごとに5コイン・10経験。重複受領は不可。7件のお店の仕事後に植木を獲得。
- 6種類の装飾、購入、9マスへの配置と移動、開店記念の認定画面。
- 日本語・中国語・英語。世界ゲームと学年マップから入場可能。

## 保存と公開範囲

第1版は単独プレイ。`localStorage` の `piko-town-v1` にお仕事、注文の途中、衣装、部屋を保存する。アカウント間・端末間同期や公開ランキングは提供しない。保存不能時は画面に通知してセッション内で続行する。壊れたデータは安全な初期状態へ戻す。読み込み済みページでは通信が切れても遊べるが、オフラインでの初回起動や再読み込みは保証しない。

既存のプライバシー選択UIを再利用する。マイク入力、チャット、プレイヤー間送信、課金、外部画像読み込みは追加していない。音声は端末の読み上げ機能を使い、利用できない場合は文字で続行できる。

## 構成

- `src/town/TownRules.mjs`: 注文・進行・保存検証・装飾・経路探索。
- `src/town/TownScene.mjs`: 描画、カメラ、操作、衝突と移動。
- `src/town/TownApp.mjs`: 画面、対話、アクセシビリティ、保存。
- `src/town/TownText.mjs`: 3言語の画面文言。
- `src/town/TownEntry.mjs` / `entry.css`: 既存学習ページの入口。

## 公開手順

この変更は静的ページとクライアントコードのみ。既存のWorkerおよびD1スキーマ・教材は更新不要。

1. 規則・回帰・最終成果物のブラウザーテストを成功させる。
2. `wrangler pages deployment list --project-name manabi-pop` で現在の本番デプロイを記録する。
3. `wrangler pages deploy ./dist --project-name manabi-pop --branch main` で既存サイトへ公開する。
4. 本番の `/town?locale=zh` と世界・学年ページのリンク、配信モジュールを確認し、独立ブラウザーで新規プレイを行う。
5. 配信障害がある場合はCloudflare Pagesの記録済み直前デプロイへロールバックする。

OAuthやAPIトークンはリポジトリ、ログの公開物、静的配信物に含めない。
