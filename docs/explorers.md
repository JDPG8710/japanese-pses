# 课外探索

用户目标 → 未指定年级（独立课外探索） → 逻辑 / 金融素养 → 容量约束与分流 / 复利与机会成本 → 水流网络 / 十月模拟 → 一个网络关卡 / 十回合 → `/explorers.html` → `tests/test_explorers_browser.mjs`。

不修改年级学科图谱、奖励或课程进度。界面使用本次请求的中文，水流标题保留日文。

水流采用有向无环图，按边数组顺序分配，所有上游处理完才处理汇合节点；多余水留在节点。开关最优解由初始状态穷举得到，当前小关卡适用。

金融采用浮点内部精度、日元显示取整。年增长 5% 换算为 `(1.05 ** (1/12)) - 1`；购买力为 `nominal / (1.02 ** (month/12))`。通胀不从现金扣款。资产持有至结束；每月新增资产和已有资产一起增长。雨天概率 30%、库存亏损 10%；其余天气利润 10–30%。参数为教学假设，非市场预测。

构建：`node scripts/build.mjs`；浏览器验证：`node tests/test_explorers_browser.mjs`。两个 Vue SFC 可直接迁入标准 Vue 3 TypeScript 项目，无外部 UI 库依赖。
