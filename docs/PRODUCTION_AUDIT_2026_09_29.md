# 正式環境の全サイト検査・修正（2026-09-29）

## 確認できた不具合と修正

1. 日本コースで「学年から選ぶ」を押すと、開いたメニューが同じクリックのdocumentハンドラーで閉じる。入口のクリックの伝播を止め、学年選択までブラウザーで検証。
2. 日本コースの390px表示でヘッダーが画面外にはみ出し、音声・ショップなどの操作が切れる。640px以下は4列2行、48pxの操作高に変更。学年・教科・マップを重ねない位置へ調整。320／390／768／1280pxで検証。
3. `?course=jp` の直リンクで文書の言語が英語のままになる。日本語とコースタイトルを初期化。
4. ログイン画面を認証スクリプト読込中に閉じると、`show()` のPromiseが解決されない。閉じる処理の準備を読込より前に行い、重複表示、Escape、スクロールとフォーカス復帰を検証。ログイン済み状態や認証判定は変更していない。
5. 本番のJavaScript無効時、公開メールがCloudflareによって `/cdn-cgi/l/email-protection` に置き換わり、連絡リンクが404になる。公開連絡先だけ公式の `email_off` コメントで囲み、サイト全体の設定は変更しない。
6. 複数の公開処理でソースが異なり、私有APIのrobots除外が失われることを確認。最新 `origin/main` の修正と、別作業で公開されたネットワーク教材・AMC 8を統合。元の未コミット作業は変更していない。
7. 古い監視はホームの200とAPIしか見ておらず、教材がホームに置き換わっても成功する。三言語資料庫の本文・canonical、運営案内、連絡先、二種類の404、robotsを追加し15項目に拡張。Pages公開前にビルドと教材・URL・SEO・入口UI検証を自動実行する。
8. ホームの「7教材」という古い説明を実際の公開テーマへ更新。前ターンのバランス教材を残し、既公開のネットワーク教材はそのまま統合。

本番のAPIは最初から正常。中英混在に見えたログイン見出しは非表示要素の初期状態で、表示時に翻訳されるため、言語バグとは扱わない。初期監査スクリプトのnetworkidle待ちとfetchのstatus参照ミスは検査側の問題であり、修正して再実行した。
