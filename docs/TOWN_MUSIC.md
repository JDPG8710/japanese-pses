# Piko — 小镇漫步

原创 32 小节、108 BPM、约 71 秒的立体声循环背景音乐。合成小提琴组担任主旋律，中提琴铺陈和声，大提琴承托低音，拨弦提供轻快的行走节奏。结构为主题、主题变化、中段、主题回归；无歌词，无第三方录音或采样。

游戏资产：`assets/audio/piko-town-strings.mp3`（160 kbps，约 1.4 MB）。作曲与渲染源码：`scripts/generate-town-music.mjs`。执行该脚本会输出无损 WAV 到 `.wrangler/town-music/`，再以 FFmpeg 编码为上述 MP3。编曲参数及原始资产信息保存在同目录 JSON 中。

播放采用 Web Audio 解码后循环，缓存同一份音频。小镇使用原速，各游戏轻微调整播放速度以配合玩法。切换场景与暂停采用淡出淡入，暂停和静音恢复后延续音乐位置，游戏结束时让出胜利音效。静音选择沿用既有持久化设置。

`npm run build` 后运行 `npm run test:town:music`：实际浏览器验证解码时长、立体声、循环边界、真实音频信号、静音、暂停恢复位置、场景速度、游戏暂停按钮及销毁清理。已于 2026-10-03 发布到 piko-game.com，并通过生产域名的真实播放与静音、暂停检查。
