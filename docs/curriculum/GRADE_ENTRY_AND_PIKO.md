# 中文／英语学年入口与 Piko Play

2026-09-05，本轮范围为学年入口、地区学年闯关地图、已有技能任务连接与显示名称更新。完整实现契约见 [中国与英语小学学年闯关实现](GRADE_ADVENTURE_IMPLEMENTATION.md)。

## 品牌

总名 Piko Play；中文「皮可乐园」，日文「ピコプレイ」。Piko 与现有角色ピコ相呼应，采用短音节设计；未做全球儿童发音／商标测试，不宣称所有语言都完全同音。

## 路径与内容范围

国家地图 → 学制 → 学年 → 学科世界 → 顺序关门／明确技能 → 游戏 → 通关解锁同学科下一关 → 返回相同学制和年级。

中国提供六三制1～6年和五四制1～5年；英语入口提供美国K～Grade 6（6为学校适用选项）、英格兰与威尔士Reception～Year 6、苏格兰与北爱尔兰P1～P7、澳大利亚Foundation～Year 6、新西兰Year 0～8。英国必须明确选地区。其他国家不默认套用美国课程，可明确选通用练习或其他学校体系。

入口的年份标签来自既有国际调查；游戏仍是已实现的补充技能，不是全科教材。内部三段仅用于编辑推荐，不表示各国学年等价。高阶段明确为基础复习；学前标签暂只提供顺序和节奏活动，不自动塞入超过基础数域的算术题。语文／语言与科学使用独立中英文内容进入各学年的第一关，不用日本语题或数学游戏替代；尚未制作的目标不显示。

路径验证：知识关门使用 `curriculum + year + lesson + locale`，操作关门使用 `curriculum + year + subject + game + level`；两者必须属于同一学年地图且已经解锁。无效或未解锁链接不自动开局；切换学制清除旧学年；游戏内保留学年与技能说明，并提供返回链接。推荐路径中的难度不能被单独改动后仍冒充原任务。

学制与年级选择按国家存于本设备。排行榜沿用已验证的游戏／难度维度，未新增按学年排名或课程修了认定。

## 验证

针对学制范围、跨体系错误链接、难度篡改、基础复习和三语命名运行 `node tests/test_grade_paths.mjs`；针对学科内解锁、旧进度兼容与关门链接运行 `node tests/test_grade_journey.mjs`。另外运行原回归、国家地图、基础题库、D1排名测试、静态构建及实际浏览器入口验证。线上发布仍需单独执行。
