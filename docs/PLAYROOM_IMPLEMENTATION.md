# Piko Playroom 首批实现 · 2026-09-09

## 需求与范围

家庭与朋友一起玩 → 独立休闲空间（不绑定年级、学科、课程奖励）→ 昵称身份、私密同桌、连续围棋、围棋入门 → `/arena.html` → 后端和真实双浏览器验证。

中日英统一品牌 Piko Playroom。现阶段只开放已有围棋，不显示国际象棋、麻将等未实现的入口。

## 已实现

- 昵称 1–20 Unicode 字符、8 个固定头像。唯一 public_id 区分同名者，账户 ID 不公开。游客 Cookie 原样保留，登录后按账户保存。游客清除 Cookie 后无法恢复原身份。
- 公共在线名单默认关闭；玩家主动开启。20 秒刷新，70 秒在线租约，同一身份多个标签页合并，取对局中优先的状态。最多显示 500 个身份；公共目录只负责名单和邀请，对局动作不经过目录。
- 家庭房间采用随机 UUID 链接／房间码，明确加入后才能读取成员列表。最多 8 人，房主选择两位参与围棋；其他成员不能读取棋局。房主离开后交给剩余第一位成员。
- 家庭在线状态每 3 秒更新，每个标签页独立续约。成员关系持续保存，30 天无活动清理。刷新时恢复上次房间，尚未加入的链接不会自动加入。
- 公共邀请有效期 2 分钟，只有被邀请者可以接受；接受后建立共享家庭房间。玩家进入家庭房间的标签页不在公共名单中续约。
- 每个家庭房间与每局 GoRoom 分离。两位成员准备后房主开局，参加者自动进入，规则在本局锁定。设置下一局不会改动当前局。
- 真人终局后双方同意再战，交换黑白、重置时间并自动进入新棋局；重复请求只创建一局。旧局先归档，新局独立 ID。家庭房间同步指向新局。
- 人机再战沿用棋盘、规则、难度，重新走 AI 准入并自动准备。名额不足时保留终局与重试入口。
- 终局页面刷新仍建立 WebSocket，能收到再战请求。旧围棋链接、邀请、匹配、棋谱继续有效。
- 五步互动教程：交叉点落子、四口气、提子、围地、两次停一手与双方确认。图示使用局部棋盘，提子和停一手调用正式规则模块。完成进度保存，支持上一步、重复练习、完成后从头重学；中日英独立文案，日语教程使用假名。练习不产生战绩或课程奖励。

## 明确边界

首批没有其他棋种、观战、聊天室或机器人补位。家庭非参与者能看到成员与本局入口，但无棋盘访问权。公共名单是最近心跳状态，并非精确到瞬间的连接人数。尚无生产并发压测或真机 Safari 验证，不承诺具体在线容量。教程属于基础规则入门，不能代替完整围棋死活与计分教学。
