# 街机重设计与玩家排行榜

追踪链：小镇/世界休闲入口 → 不绑定年级或学科的音乐、创作体验 → rhythm（音乐节奏）、bubble 内部 ID（小小设计师） → 原有挑战与奖励结算。内部 ID 保留以兼容建筑、邀请和存档；泡泡及旧鼓队的最好成绩不混入新游戏。

- 节奏鼓队：48 个固定谱面音符，100–120 BPM 原创合成伴奏，D/F/J/K 与 1–4 / 触控输入，精准/很好/错过与连击，暂停时停音乐，退出释放音频和动画。
- 小小设计师：飞机、汽车、手机，零件拖拽、轮廓提示与吸附，零件配色、涂鸦、橡皮、撤销、清空、PNG 下载。全部零件及有效涂鸦完成后才结算，得分表示操作完成度，不评价儿童的审美。
- 玩家排行榜：六款街机及五款小镇挑战接入 `/api/arcade/{start,finish,leaderboard}`。游客可查看，登录账号可写入；按游戏、关卡、版本隔离，每位账号只显示最高成绩，并列分数同名次，公开随机昵称，最多 50 人。原世界/基础课程排行榜沿用已有服务器实现。
- D1 迁移：`migrations/0016_arcade_rankings.sql`，新增独立表与索引，不修改旧数据。旧本机成绩不自动上传。
