### 3.2 学年の数字を国際変換しない

画面言語、学習言語、教育課程、学年、習熟度を別々に選べるようにする。国・地域は居住地や国籍の証明ではなく、学習課程の選択。IPから課程や言語を強制しない。

学習段階A/B/Cは教材設計用の内部ラベルとし、A＝具体的操作、B＝説明と比較、C＝統合と転移。日本の1〜2・3〜4・5〜6年に概ね対応する設計から始めるが、他国の同じ数字の学年と同等とみなさない。学年別の正式対応は目標ごとに審査する。

初回で保存設定も指定教材もない場合は、簡潔なモード選択を標準入口とする。ただし毎回同じ順番を強制しない。プレイヤーは「つづき」「ゲーム一覧」「学年マップ」「毎回選ぶ」から起動画面を選び、ゲーム優先／学年優先の順番や任意の紹介表示を変更できる。「学ぶカリキュラム」と「表示言語」はどの入口からも変更可能とし、年齢、性別、Googleログインを開始条件に戻さない。詳細は [入口設計](ENTRY_EXPERIENCE_DESIGN.md) を正とする。

- 学年モード：その課程の学年マップ → 対応教科・目標 → 遊び方。未設定の教育課程・学年は一つの選択パネルで補う。
- ゲームモード：遊び方 → 対応する教育課程・学年・目標 → 開始。設定済みの項目を毎回質問せず、対応する内容を先に表示する。
- 続き・教材リンク：有効な目標・ステージの概要 → 利用者の開始操作。ホームやモード選択を必ず通過させない。
- 順番を変えても、開始時には課程・版・学年・学科・学習目標・ゲーム型・題庫の組が確定していなければならない。
- 同一アカウントで複数課程・学年を学べる。挑戦入口を成績で封鎖しない。
- 未審査・未実装の教科は非表示または「準備中」。日本語問題や他国の学年へ自動代替しない。

## 5. 1つの学習目標から作るステージ

1ミッション系統を1つの万能問題プールにしない。系統の下に単一の学習目標を持つ単元を作り、必要な段階だけを配置する。

| 段階 | 遊び方 | 残す学習証拠 |
| --- | --- | --- |
| 1 発見 | 観察、聞く、具体物を動かす | 何に気づいたか。無採点の導入も可 |
| 2 基礎 | 対応付け、配置、短い判断 | 独力の正答と典型的な誤り |
| 3 操作 | 組み立て、並べ替え、条件変更 | 手順、試行、修正 |
| 4 説明 | 根拠選択、資料への印、短文 | 答えと根拠がつながっているか |
| 5 応用 | 初見の生活場面、複数条件 | 方法選択、転移、結果の確認 |
| 6 創作・振り返り | 設計、作品修正、別解 | 制約の充足、改善点、次の目標 |

78系統×6段階＝468という計算を実装済みゲーム数・完成ステージ数・独立問題数として広告しない。段階ごとの教材が完成し審査されたものだけを公開数に数える。

### 出題と結果の契約

- 通常の知識練習は既存どおり1セッション10問。問題と選択肢を独立にシャッフルし、同一セッション内で重複させない。
- 公開する知識問題プールは目標・地域・学習言語・難度ごとに最低30件を設計目安とし、10件しかない小範囲は内容拡張前に公開を止める。有限の文字集合などは、偽の水増しではなく別の学習操作で構成する。
- 外国語英語の既存「各レベル200問以上」の要件は維持。200は独立にレビューできる問いの数であり、選択肢の並べ替えや人名置換の組合せ数ではない。
- 抽選は型・下位目標ごとに配分し、最近の出題を可能な範囲で避ける。履歴除外で不足した場合も同学習目標内でのみ緩め、他国・他学年の問題を混ぜない。
- 読解は文章単位で選んでから設問を選ぶ。10問の場合は複数文章に配分し、設問から答えが相互に漏れないようレビューする。
- 「同じ概念の復習」と「同じ問題の重複」を区別する。構造的に同じ問題を数値変更だけで連続させない。
- 選択は色＋枠＋記号で即座に表示。間違い1回目は穏やかな反応、2回目は観点、3回目は説明。ヒント後の成功と独力の成功を別記録にする。
- 社会の装飾絵文字、答えだけ目立つ選択肢、質問文での答えの言い換えを禁止。ただし読解本文・地図・実験結果など、本来読むべき証拠を削除しない。
- 現在の通常3分制限をこの設計作業では変更しない。将来の長文・創作は別の時間契約を設計し、時間切れを誤って合格にしない。習熟を読む速さだけで判定しない。
- 通常10問の合格案は8問以上かつ必須目標の達成。基準は単元ごとに明示し、既存報酬基準の変更は実装レビューの対象とする。
- 失敗・時間切れ・0点は報酬も解放もなし。成功時に次の有効ステージへ進める。課程末尾は成果画面へ。成人確認が必要な作品は「提出済み」と「確認済み」を分離する。
- 正答が唯一でない創作・説明を単純な完全一致やAIの単独判定で落とさない。

## 6. 英語圏向けに作り直す内容

### 母語英語と外国語英語の分離

| 系統 | 内容 | 対象にしないもの |
| --- | --- | --- |
| EN 母語リテラシー | 音韻・文字対応、単語認識、流暢さ、語彙、文学・情報文読解、文章作成、話す・聞く | 英日翻訳ペア、英検級を学年の代理とすること |
| FL 外国語 | やり取り、語彙、聴解、短文・長文、場面表現 | 国籍から英語力を推定すること |

EN初期：聞いた音を分ける → 文字を選ぶ → 語を作る → 適切な読みやすさの短文を読む → 意味を確認。

EN中期：物語の出来事を並べる → 本文の根拠を示す → 人物の行動を推論 → 段落を編集。

EN後期：2資料を比較 → 主張と根拠を検討 → 構成を設計 → 下書きを修正。単に文章を長くするだけで難度を上げない。

米国向け参照候補は[CCSS英語](https://corestandards.org/english-language-arts-standards/)・[数学](https://corestandards.org/mathematics-standards/)、科学は知識・横断概念・探究実践を組み合わせる[NGSS](https://www.nextgenscience.org/glossary/three-dimensions)。いずれも地域の正式採用状況と個別目標を別途照合する。

### 表示と教材の地域化

画面に ja-JP、en-AU、en-NZ、en-US、en-GB、zh-Hans-CNを用意する設計とする。en-GBは英国の単一教育課程を意味しない。zh-Hans-CNも居住地・国籍の証明ではなく、教育課程は別に選ぶ。

- colour/color、maths/mathなどを地域別に管理。正当な英語変種は、変種自体を問う場合を除き誤答にしない。
- 音声は地域と発達段階を確認した素材を優先。端末読み上げに適切な声がない場合は代替字幕・操作を提供し、別言語の音声で穴埋めしない。
- 価格はJPY/AUD/NZD/USD/GBPを明記し、ドル記号だけで国を推定させない。換算練習は固定した教材用レートと明示する。
- 測定は地域に応じた単位を明記。米国向けでもメートル法を隠さず、教材の目的に応じて使い分ける。
- 季節、昼の長さ、月の見え方は国旗ではなく観測地・日付・視点で決める。南北半球で画像を単純反転しただけの説明にしない。
- 地理・歴史・制度・道路安全・公共サービスは地域別資料を用意。都道府県を米国の州へ文字置換して終えない。
- First Nations、Māori、Native Americanなどの内容は多様性を前提に出典・利用許諾・地域レビューを行う。マスコットや単一の文化像へ縮約しない。
- 読み上げ、キーボード操作、字幕、静止画、低モーションを選べる。マイク・カメラ・位置情報を必須にしない。

## 7. データと経路の設計契約（未実装）

全コンテンツが次の追跡鎖を持つ。

`利用目的 → curriculumId / version → yearKey → subjectId → objectiveId → missionId → interactionType → poolId → route → evidence`

| 項目 | 役割 |
| --- | --- |
| curriculumId / curriculumVersion / effectiveFrom | 適用地域・教育課程・改訂時点 |
| yearKey / yearLabel | F、R、Y0、Y8、P7、Kなどを失わない学年キー |
| subjectId / strandId / objectiveId | 言語非依存の学習内容ID |
| uiLocale / contentLocale / learningLanguage / languageRole | 表示・本文・学ぶ言語・母語/追加言語の区別 |
| standardReferences / alignmentStatus | 正式出典と条項、確認担当、確認日。未審査は draft |
| missionId / stageId / interactionType / contentVersion | 遊び方と保存対象 |
| prerequisiteObjectiveIds | 同課程で妥当性を確認した前提関係 |
| itemId / conceptSignature / stimulusId / variantId | 項目、意味上の重複、共通資料、変種の管理 |
| answerModel / misconceptionTags / rubric / evidenceType | 正答判定、誤概念、採点基準、証拠の種類 |
| regionContext / accessibility / reviewStatus | 観測地・単位等、代替操作、教材レビュー状況 |

本番教材は既存のデータベース経由、ローカルは既存キャッシュ経由という契約を維持する。未実装の新スキーマを本番インポートに混ぜない。

進捗のキーは課程・版・学習目標・ステージを含める。同じ「6年」の別課程へクリアを自動コピーしない。等価な学習証拠の再利用は明示的な対応表とレビューを通す。

旧27ノードとクリア履歴は残す。子目標へ分割した場合、旧クリアを全子目標の合格に変換しない。「旧版完了」と、新版で確認できた目標を区別し、不足分は任意の短い確認課題を提示する。旧コイン・購入品を移行のために消さない。
